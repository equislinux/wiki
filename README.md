# X Linux Wiki

Documentation for the X Linux project, aggregated from all the repositories of
the equislinux organization. Every section exists in English (`en`) and Spanish
(`es`).

## Repositories

- `x/` — the distro: archiso profile, text installer, ISO build.
- `scripts/` — provisioning payload and CLI (`x`), packaged as `x-scripts`.
- `xpkg/` — Rust package builder (de-prioritised during the reboot).
- `xpm/` — Rust package manager (de-prioritised during the reboot).
- `x-repo/` — binary package repository (`[x]`) and web portal.
